# PROYECTO-SPRINT-7
ESTE SERA EL PROYECTO DEL SPRINT 7
en este proyecto, se creo una aplicacion con dos botones para ver un histograma y un grafico de dispersion, el histograma sirve para ver como se distribuye una variable numerica, por ejemplo el kilometraje de los coches y el de dsipersion sirve para ver la relacion de dos variables numericas


El link de render : https://proyecto-sprint-7-kufz.onrender.com

descripcion del proyecto: 

En el archivo de app.py se crean graficos 

En requirements.txt se llama a las librerias que ocupamos en el proyecto pandas, plotly y streamlit

El archivo vehicles_us.csv contiene la informacion que hemos analizado inluye el precio del vehiculo, año del modelo, condicion del modelo que puede variar en exelente, buena o como nuevo, ya que son coches ya usados, luego te dan el numero de cilindros del coche, luego el tipo de combustible que usan, luego sigue el odometro, que eso mide el kilometraje, luego el tipo de transmicion que es manual o automatica, luego sigue la clase del coche , luego color del coche,luego otra columna que investigue y es is_4wd que significa que si es four wheel drive, para indicar si un vehículo cuenta con sistema de tracción en las cuatro ruedas, luego la fecha de la publicacion del coche y los dias listado, lo que analizamos principalmente fue la relacion del odometro y el precio, en nuestros archivos hicimos varias pruebas, haciendo distintos graficos y sobre todo en render hice una pagina web para poder observar esas graficas.
